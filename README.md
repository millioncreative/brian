# brian

This repository contains a simple Sudoku game implemented in Python.

## Running the game

```bash
python sudoku.py
```

The program will prompt for a difficulty level between 0 (trivial) and 100 (hardest).
After displaying the puzzle, the timer starts. Enter moves in the format `row col value`.
Enter `q` to quit. When the puzzle is solved, the elapsed time will be printed.

## Tests

Run tests with:

```bash
pytest
```
